# Lumina Task Manager

Lumina Task Manager is a modern, lightweight system monitor built with PyQt6 for the Lumina ecosystem.

## Features
- Real-time CPU monitoring
- RAM monitoring
- Process management
- Process termination with confirmation dialog

## Requirements
- Python 3.10+
- PyQt6
- psutil
- pyqtgraph

## Installation

pip install -r requirements.txt
python lumina_taskmanager/main.py
